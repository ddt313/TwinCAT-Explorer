# Review and commit per object

In the **Source Control** sidebar:

- **TwinCAT Changes** lists the methods, properties and objects that changed, not the XML files. A click shows the
  change in the split editor; `+` stages one object, `↶` discards it, and the `✓` button of the view commits
  what is staged.
- The view's title bar switches to the branch's changes since another branch, what a merge request shows.
- **TwinCAT Commits** lists the commits, each expanding to the objects it changed.
