# Go to any object

**Ctrl+Alt+T** (`TwinCAT: Go to Object...`) lists every POU, method, property, DUT, GVL and interface of the
workspace. Type part of a name (`valve.cl` finds `FB_Valve.Close`) and press Enter.

In the editors, **F12** goes to a definition, **Shift+F12** lists the references, and **Alt+Left** /
**Alt+Right** go back and forward through the objects you opened.
