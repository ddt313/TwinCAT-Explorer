# Search the code

**Ctrl+Shift+Alt+F** (`TwinCAT: Search...`) finds a text in the Structured Text of the objects, never in their
XML. The results are in the **TwinCAT Search** tab of the Panel, beside Problems and Output, per object and
section; a click opens the split editor at the match.

Match Case (Alt+C), Match Whole Word (Alt+W), regular expressions (Alt+R) and Skip Comments are buttons of the
input box. Right-click a project or folder of the tree for `Find in Project...` / `Find in Folder...`.
