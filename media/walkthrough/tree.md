# The Solution tree

The **TwinCAT** icon in the Activity Bar opens the TwinCAT projects as XAE's Solution Explorer shows them: each
`.tsproj`, its PLC projects, `References`, folders, and inside a POU its methods, properties, actions and
transitions. Changed objects are marked `M` (changed) or `A` (new).

- A click opens the object in the split editor, the Declaration above the Implementation.
- The `+` button of the view adds a POU, DUT, GVL, interface, folder or library; right-click a node for the rest
  (add a method, rename, move, delete, history).
- **History**, below the tree, lists the commits that changed the object you have open.
